# Portus Logistics Website

[![Website Status](https://img.shields.io/website?url=https%3A%2F%2Fportuslogistics.co%2F)](https://portuslogistics.co/)

A modern, highly responsive corporate website and web application built for **Portus Logistics**—a comprehensive global supply chain and freight management provider. This repository hosts the clean frontend interface, business logic, and dynamic calculator tools.

🔗 **Live Link:** [https://portuslogistics.co/](https://portuslogistics.co/)

---

## 🚀 Key Features

*   **Service Portfolios:** Highlights tailored supply chain offerings across core sectors like Aerospace, Defense, Automotive, Healthcare, and Green Energy.
*   **Interactive Shipping Estimate Calculator:** A pure JavaScript utility designed to calculate:
    *   Assessed values based on machinery tonnage and production year.
    *   Incoterms integration (FOB, CIF, Door-to-Door FCA).
    *   Granular cost breakdowns including Import Duties (7.5%), Machine GST (18%), China Trucking, and Fixed Port/Agency fees.
*   **Modern UI/UX:** Built with native web technologies featuring clean transitions, video integration, and optimized asset loading.
*   **Lead Generation:** Integrated responsive forms for client inquiry routing (`sales@portuslogistics.co`).

---

## 🛠️ Tech Stack

*   **Structure:** HTML5
*   **Styling:** CSS3 (Custom styles and responsive grid systems)
*   **Scripting:**  JavaScript (ES6+)
